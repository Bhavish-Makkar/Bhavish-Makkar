## Selected engineering work

### Secure METAR Weather Intelligence MCP Server

Built a production-oriented MCP server that lets AI applications query aviation weather data using natural language.

- Async Python/FastMCP tools over MongoDB with rich station, FIR, weather and time filters
- Azure AD JWT verification, role-based tool visibility and fail-safe authorization
- Identity-aware sliding-window rate limiting at **20 requests/minute per user**
- Bounded results, health checks and structured tool contracts for reliable AI integration

### LLM Client Automation Platform

Designed an LLM pipeline that retrieves, structures and summarizes case data from multiple internal systems.

- Combined context engineering and prompt optimization with LLaMA/Mistral and Azure AI Foundry
- Built API-driven workflows with MongoDB-backed data access and output validation
- Reduced recurring manual drafting effort by approximately **2-3 days per month per fee earner**

### RAG-Based Case Management Q&A

Built a case-aware retrieval system over structured case-management data.

- Extracted, processed, chunked and embedded case data with case-level metadata
- Combined semantic retrieval with LLM generation for contextual answers
- Supported natural-language access to case history, activities, hearings and related information
